## ⚠️ 当前限制的影响

### 最小值 0.1 的影响

- **优点**: 防止缩放过小导致内容不可见
- **缺点**: 对于大画布可能限制过严
- **实际效果**: 10%缩放下，100×100像素的画布显示为10×10像素

### 最大值 2.0 的影响

- **优点**: 防止过度放大导致性能问题
- **缺点**: 对于精细编辑可能不够
- **实际效果**: 200%缩放下，每个像素显示为2×2像素

## 📊 性能考虑

### 最小缩放的性能影响

- **渲染像素数**: 与缩放值成反比
- **0.1缩放**: 渲染像素数为正常的1%
- **内存使用**: 缩放不影响内存，只影响渲染

### 最大缩放的性能影响

- **渲染精度**: 与缩放值成正比
- **2.0缩放**: 每个像素渲染为4个屏幕像素
- **网格渲染**: 高缩放时网格线更清晰但计算量增加

```typescript
// 预定义的智能缩放级别
const ZOOM_PRESETS = [
  0.1, 0.25, 0.5, 0.75, 1.0, 1.25, 1.5, 2.0, 3.0, 5.0, 10.0,
];

// 跳转到最近的预设级别

  );
};
```
